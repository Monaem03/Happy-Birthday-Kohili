KOHILI BIRTHDAY STUDIO — READY PROJECT

1) Extract this ZIP.
2) Open the extracted folder in VS Code.
3) Put your own song in this folder named exactly: music.mp3
4) Open index.html with Live Server.

WHAT'S INCLUDED
- Tailwind CSS CDN + custom responsive CSS
- Anime storyboard illustrations and a cinematic scene player
- Animated camera zoom/pan, fade transitions, particles, scene-specific effects
- Play/pause, restart, chapter navigation, progress timeline, small note messages
- Looping music; browsers may require one tap to allow audio

IMPORTANT LIMITATION
The scene artwork is a set of illustrations. The cinematic player adds movement, camera effects,
transitions and overlays; it is not a true generated video with every character body part animated.
For true frame-by-frame anime movement, a dedicated animation/video asset would be needed.
Internet is needed for Tailwind CDN and Google Fonts.
